# 📊 Sales Dashboard Project

## 📌 Overview
This project presents an interactive Sales Dashboard designed to analyze and visualize business performance. It provides insights into sales trends, profit distribution, and customer behavior across different product categories.

The dashboard enables users to explore data dynamically using filters and gain meaningful insights for decision-making.

---

## 🚀 Features
- 📊 Category-wise Sales Analysis (Beauty, Clothing, Electronics)
- 📈 Profit Trend Visualization
- 📅 Monthly Sales Analysis
- 🧑‍💼 Top Customers Identification
- 🎛️ Interactive Filters (Year & Product Category)
